## Blob Storage

Container Name: labfiles

Uploaded File: test.txt

Purpose:
Blob Storage is used to store unstructured data such as documents, images, videos, backups, and application files. It provides scalable and secure storage that can be accessed when needed.



## Azure File Share

File Share Name: homelabshare

Purpose:
Azure Files provides fully managed file shares that can be accessed by multiple users or applications. It is commonly used for shared folders, application data, and file storage in cloud and hybrid environments.



## Security Features
The storage account includes several security features to help protect data, including:
 -Access Keys for administrative access.
 -Shared Access Signatures (SAS) for limited and temporary access.
 -Identity and Access Management (IAM) for rolebased permissions.
- Networking and Firewall settings to control access to the storage    account.
 -Encryption to help protect stored data.
